# Zepto Data & AI Platform

This repository contains three modules that together form the Zepto Data & AI Platform project.

---

## 📂 Structure
- `/data_pipeline` → Web scraping, cleaning, currency conversion, SQLite storage, SQL queries.
- `/analytics` → Titanic dataset profiling, EDA, modeling, imbalance handling, regression side‑task, saved pipeline.
- `/support_assistant` → GenAI support assistant with LangGraph + FastAPI, policy corpus, Docker setup.
